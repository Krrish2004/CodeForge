# Screenshots for CodeForge

This directory contains screenshots used in the main README.md file.

Required screenshots:
1. banner.png - A wide banner showing the CodeForge dashboard
2. dashboard.png - Screenshot of the user dashboard with analytics
3. problem-analytics.png - Screenshot of the problem analytics page
4. contest-tracker.png - Screenshot of the contest tracking interface
5. submission-details.png - Screenshot of the submission details page

For GitHub to display these images properly, please replace this file with actual 
screenshots of your running application. You can take screenshots of your app while 
it's running on localhost:3000 and save them with these filenames.

Note: For optimal display, use a 16:9 aspect ratio for the banner and square or 4:3 
for the other screenshots.
